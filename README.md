# HNG Stage 1B: The Profile Card ✨

A sleek, whimsical, and highly accessible Profile Card built strictly following the **HNG Stage 1B Requirements**. This project demonstrates an elegant mastery of semantic HTML5, responsive CSS without external frameworks, and Vanilla JavaScript to handle dynamic state and playful interactions.

## 🚀 Features

- **Semantic HTML5:** Strict utilization of tags like `<article>`, `<figure>`, `<nav>`, `<header>`, and `<section>`.
- **Automated Testing Ready:** All required components are explicitly tagged with `data-testid` attributes following the project specifications exactly.
- **Dynamic Time Integration:** Instantly tracks and displays standard Unix Epoch `Date.now()` milliseconds on the UI, refreshing gracefully on a steady loop.
- **A11y Compliant:** Meets WCAG AA text contrast standards, implements explicit visible `outline` parameters for keyboard tab-focusing, utilizes `aria-live` regions, and implements safe external links (`noopener noreferrer`).
- **Whimsical Interactions:** Beautifully animated falling flowers (🍁, 🍂, 🌸, 🌼, ✨) configured to shower down the screen upon engaging the avatar picture.

## 🛠️ How to Run Locally

Because this project is built entirely independent of modern frameworks or bundlers (No React, Vue, Webpack, etc.), it requires **zero installation**.

1. **Clone or Download the Repository:**
   Provide the local pathway where the folder is located.
   
2. **Launch the Application:**
   Navigate into the project folder (`hng-profile-card`) and simply double-click the `index.html` file to open it directly in your default browser.
   
3. **Live Server (Optional but Recommended):**
   If you have VS Code installed, running the **"Live Server"** extension on `index.html` offers hot-reloading for rapid UI development!

## 🎨 Technologies Used

- **HTML5:** Pure, semantic layout.
- **CSS3:** Custom Variables, Animations (`@keyframes`), Flexbox, CSS Grid.
- **Vanilla JavaScript Setup:** Pure DOM manipulation & Event listeners (No heavy React logic).
